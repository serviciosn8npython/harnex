# PROMPT MAESTRO — SERVICIO B2B DE DASHBOARDS, REPORTES Y CONTROL DE GESTIÓN

## 1. Problema operativo y dolor financiero
- Dolor central: Discrepancias entre pedidos comerciales, facturación emitida (SII) y notas de crédito/anulaciones. Horas perdidas cuadrando Excels.
- Riesgo de negocio: Decisiones tomadas sobre números de ventas no conciliados con la realidad financiera.

## 2. Perfil del Cliente Objetivo (ICP)
- Pymes comerciales, distribuidoras y empresas de servicios con módulos de ventas y contabilidad desconectados.

## 3. Alcance y Entregables (MVP)
- Inventario de fuentes y Diccionario de Métricas Oficiales.
- Modelo de datos dimensional (Tablas de Hechos y Dimensiones).
- Medidas DAX documentadas para conciliación de ingresos reales vs brutos.
- Tablero de control ejecutivo con visualización de cascada de discrepancias.
- Protocolo de actualización y validación periódica.

## 4. Stack Técnico
- Power BI Desktop / Power BI Service o Dashboards web en Next.js.
- Power Query, SQL y Python/Pandas para preparación y auditoría de datos.
- Bases de datos relacionales (PostgreSQL / SQL Server) y almacenamiento seguro.

## 5. Reglas de Negocio y Límites
- IA Interpretativa: Asistencia en la documentación, formulación de consultas analíticas y redacción de diagnósticos ejecutivos.
- Lógica Determinística: Todo el cálculo numérico, agregaciones DAX, conciliación contable y reglas de reconocimiento temporal.
- Prohibición estricta: La IA no calcula métricas directamente en memoria ni asume correlaciones causales sin sustento en los datos.
